## 需求概述

对 `d:/lzkgit/my_blog_` 前端项目做两步重构：**先删除全项目扫描出的未使用代码，再为全部 82 个源文件补充尽可能详细的中文注释**。全程只改前端，后端由用户自行处理。

## 核心功能

1. **删除未使用代码**（已全量扫描并抽样复核，清单确定）

- 整文件/空目录：空目录 `src/ademo/`、`src/mock/`；孤儿文件 `src/api/education.ts`、`src/data/design.ts`、`src/data/videography.ts`、`src/data/photography_projects.ts`
- 死类型：教育经历链（`EducationVo`/`ExperienceVo`/`CompetitionVo`/`HonorsVo`/`Experience`/`HonorsData`/`CompetitionGroup`/`EducationPageContent`）
- 死符号：`PROJECT_DATA`、`pickList`、`setTheme`、`resetRouteState`、`meta.public`、`schema.ts` 的 `YESNO`
- Vue 行内：`admin/dashboard` 未使用图标（Headset/Share/Notebook）、`crud/index.vue` 未使用 `permissions`、17 处 `advanced` ref、19 处 `isEdit` computed、15 处 `.thumb` 未使用样式

2. **补充详细注释**：全项目 82 个文件（含 30+ 个 admin 后台页），中文注释，只加不改逻辑

## 已确认的取舍

- 旧占位数据全部删除，只保留 `src/data/dev.ts`（首页精选写死数据依赖它）
- 只删教育经历链；`SongVo`/`Song`、管理员 6 个 `Admin*Vo`、`system.ts` 9 个 `Sys*` 类型一律保留，仅补注释
- 注释范围：全项目 82 个文件

## 不可破坏的既有事实

- 首页「精选作品」= 写死的 `FEATURED_PROJECTS`，不请求 `/api/projects`
- 作品分类始终来自 `/api/project-categories`，`PortfolioGrid.vue` 的分类取交集兜底保留
- `CONTENT_PAGES`（19 页）与 `SYSTEM_PAGES`（3 页）由后端菜单 `perms` 字符串动态引用，**不是孤儿，禁止删除**

## 技术栈

Vue 3.4（`<script setup>` + TypeScript）+ Pinia + Vue Router 4 + Vite 5 + Element Plus + Less/Tailwind。无 ESLint；校验靠 `npx vue-tsc --noEmit -p tsconfig.json` 与 `npm run build`（`vue-tsc && vite build`）。

## 实现方案

**策略：先删后注、分批提交、每批校验。** 删除阶段对每个符号做「全项目 grep 零引用」二次确认后再删；注释阶段严格只插入注释文本，不改动任何语句、类型与样式值，确保行为零变化。

**关键决策与权衡**

- 删除优先做「整文件 + 死类型」，风险最低收益最大；Vue 侧行内删除采用「逐文件 grep 确认」而非批量正则替换，避免误删 `system/user`、`content/article`、`content/experience` 中模板在用的 `isEdit` 以及 4 个页面中真实使用 `.thumb` 的情况。
- 保留「仅文件内部使用」的 export（`Admin*Vo`、`Sys*` 类型、`I18nText` 等）：它们是 `AdminVoMap` 类型推导锚点与未来类型收窄入口，按用户选择不动，仅补注释说明用途。
- 重复类型（`types/index.ts` 的 `SocialLinks`/`ContactContent`/`Song`/`PortfolioPageContent` 与 `data/` 下同名定义）保留 `types` 中的声明并加注释标明「以 data/ 下定义为准」，避免误伤。
- 注释统一中文，与项目现有风格（文件头一行职责说明 + 关键逻辑行内中文注释）保持一致。

## 执行注意事项

- 每删一个符号前先搜索确认零引用，含模板、`<component :is>`、字符串动态引用、路由 lazy import
- 删除 `src/api/education.ts` 后必须同步移除 `src/api/index.ts` 的 `export * from './education'`
- 删 `PROJECT_DATA` 后清理 `src/data/projects.ts` 中随之失联的 import（`design`/`videography`/`photography_projects`）
- 每批删除后立即跑 `vue-tsc --noEmit`；全部完成后再跑一次 `npm run build` 做完整验证
- 注释阶段禁止修改代码逻辑、变量名、样式值；不改后端、不改 `.env`、不提交 git
- 性能与体积：删除约 12KB 死数据 + 数十处死代码，纯收益，无运行时影响

## 注释规范（全项目统一）

1. **文件头块注释**：职责、数据来源（接口/本地写死）、被谁引用、注意事项
2. **导出符号 JSDoc**：用途、参数、返回值、边界与缺省行为
3. **关键逻辑行内注释**：分支判断顺序、兜底/降级策略（如封面图 3 态、分类取交集）
4. **模板块注释**：结构分区（Hero/筛选栏/网格/弹窗）
5. **样式分区注释**：按区块分组标注

## Agent Extensions

### SubAgent

- **code-explorer**
- Purpose：删除前对每个待删符号/文件做全项目引用核验（含模板、动态字符串、路由 lazy import）
- Expected outcome：输出「零引用可删」或「存在引用需保留」结论，避免误删 `CONTENT_PAGES` 动态引用页与模板在用的 `isEdit`/`.thumb`

### Skill

- **lsp-code-analysis**
- Purpose：对 `setTheme`、`resetRouteState`、`pickList`、各 VO 等符号做语义级 find-references / call-hierarchy 复核（比纯文本 grep 更可靠，能识别类型引用）
- Expected outcome：拿到权威引用计数，确认删除安全；注释阶段用它快速获取文件大纲与符号定义，保证注释描述与真实签名一致
